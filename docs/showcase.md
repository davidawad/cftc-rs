# Showcase

| Image | Shows | Reproduce |
| --- | --- | --- |
| `showcase/cds-daily.png` | `cftc cds daily` over a synthetic CDX.NA.IG week, including one off-scale print on 2026-03-04 | `docs/showcase/make-screenshots.sh` |

All showcase data is generated by `docs/showcase/make-sample.py`; every value is invented. The script builds the CLI, runs it offline against that cache, formats the JSON lines with `docs/showcase/table.py`, and renders the PNG with charm `freeze` when it is installed.
